# 本地性能 · [English](PERFORMANCE.md)

以下仅为 **Windows 本机**观察：OpenResty 1.25.3.2、一个 worker、32 个 Go 客户端，
使用[151,253 条 IP 快照](../examples/abuseipdb-30d/README.zh-CN.md)。
它不是 Linux、其他库或线上站点的测试结果。

| v1.3.3 测试 | 结果 |
|---|---:|
| 20 秒、单个放行 IP | 52,324 req/s；0 错误 |
| 20 秒、24 个轮换放行 IP | 51,346 req/s；0 错误 |
| 10 秒、名单命中 | 每秒 4,881 次预期 Nginx 444 断连；0 错误 |
| 同一实例无钩子/完整钩子 204，六轮各 5 秒交错 | 带钩子吞吐低 2.23%–3.67%，配对中位数 2.90% |

无钩子与受保护路径的 URI/响应头略有差别，因此百分比是**本地完整测试路径
差异**，不是仅二分查询的开销。极简 204 接口会放大固定逐请求成本；真实后端、
CPU 余量、TLS/WAF 和缓存会改变影响，无法据此计算线上下降比例。

151,253 条地址的 FFI 数组净大小为 605,012 字节，/16 偏移索引为
262,148 字节，合计 **867,160 字节**；这不包含 Lua、分配器、worker 和系统开销。
本地压力后 master+worker 合计约 27.8 MiB Working Set、9.8–10.0 MiB
Private Bytes。Windows 进程求和不是 Linux 共享内存或 PSS 测量。

最终源码保留三路二分和有界差值右移。已测试的 `lower_bound` 未稳定胜出。
原始本地报告仍保留在开发机 Git 忽略的 `localtest/` 中。
